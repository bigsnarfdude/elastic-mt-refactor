An SAE rediscovers the microtubule order parameter — as a 2-atom director code

Sprint S3 — sparse autoencoder on cortical-MT trajectory geometry

2026-07-05 · trained on the S1 ablation snapshots · nigel

Ask an unsupervised sparse autoencoder to compress the geometry of a self-organizing microtubule array, and it independently reinvents the exact quantity biologists hand-designed: nematic order. Not as one neuron — order is rotation-invariant, so no single direction-tuned feature can be it — but as a minimal two-atom code that recovers S₂ at r = 0.99.

TL;DR

  • The obvious hypothesis fails. No single SAE feature is S₂ (best 0.68, and it swings 0.99→0.24 between held-out seeds). A single feature is a direction detector, and S₂ is direction-blind.
  • But two atoms nail it. Reconstruct the array's angle histogram from just its top-2 order-carrying atoms → S₂ comes back at r = 0.99, stable across both held-out seeds.
  • Order is exactly 2-dimensional. 1 atom → 0.69, 2 atoms → 0.99, 3 atoms → 0.994. A third adds nothing: the learned order code is a 2D (direction + magnitude) object.
  • It matches the physics. The hand-designed pair is (Ω = director angle, S₂ = scalar order). The SAE arrives at the same decomposition on its own — no labels, no fitted probe.

The setup

Cortical microtubules self-organize from a disordered tangle into a globally aligned array. Biologists summarize "how aligned" with the nematic order parameter S₂ — essentially the strength of the 2nd harmonic of the angle distribution. The question: if you train a sparse autoencoder (a model that learns a small dictionary of reusable "atoms") on raw per-region angle histograms, with no access to S₂ — does it rediscover S₂ on its own? If yes, the hand-designed order parameter is a natural axis of the data, not just a human convention.

The training set is a gift from Sprint S1: 25 rule-ablation runs whose order spans S₂ ≈ 0.07 (disordered) to 0.89 (highly aligned) — the variation you need for the question to even be askable.

What we did

What we found

One atom is a direction detector, not an order meter. The best single feature (tuned to 67.5°) correlates 0.99 with S₂ when the array happens to order near 67.5°, but only 0.40 when it orders elsewhere. Pooled: 0.68, and seed-unstable (0.99 vs 0.24). That's the pre-registered single-feature hypothesis failing — for a reason.
Two atoms recover S₂ at r = 0.99, seed-stable. The two order-carrying atoms are tuned to 112° and 69° — spanning the nematic plane. Their joint reconstruction is rotation-invariant, so it reads out S₂ regardless of which direction the array picked. Same 0.99 on both held-out seeds.
The learned code matches the physics. Biologists describe order with two numbers: the director angle Ω and the scalar order S₂. The SAE, given no labels, lands on the same 2D structure — direction-selective atoms whose combined magnitude is the order parameter.

What it means

The tempting test — "is there a single neuron for order?" — was the wrong question, and its failure is informative rather than disappointing. Order (S₂) is a rotation-invariant magnitude; you cannot encode a magnitude that ignores direction in a single feature that is defined by a direction. The SAE instead does the sensible thing: it learns direction-selective atoms and represents order as their combined strength. Two atoms are necessary (a plane has two axes) and sufficient (a third adds nothing) — so the unsupervised model recovers precisely the (Ω, S₂) decomposition the field arrived at by hand. That's a small but clean case of an interpretability method rediscovering a known scientific order parameter from raw simulation geometry.

What's next

  • Name the two atoms explicitly as the cos2θ / sin2θ director components and show a live (Ω, S₂) readout tracking an array as it orders.
  • A resampling-trained SAE (the data is only ~3-dimensional, so most atoms die) for a cleaner, fuller basis.
  • Push the same probe to features the biologists didn't hand-design — defect density, bundle structure — where an SAE might find something new.
